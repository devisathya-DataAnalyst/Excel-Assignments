# Excel Data Cleaning and Transformation

## Project Overview
This project demonstrates data cleaning and preprocessing using Microsoft Excel. The objective is to transform a raw product dataset into a structured, consistent, and analysis-ready dataset.

## Objectives
- Identify and handle missing values.
- Standardize inconsistent text formats.
- Correct spelling errors in categorical data.
- Identify and remove duplicate records.
- Split and merge columns for better data organization.
- Apply currency and conditional formatting.

## Tools Used
- Microsoft Excel
- Excel Data Cleaning Tools
- Conditional Formatting
- Text Functions

## Data Cleaning Process

| Task | Action Performed |
|---|---|
| Missing Values | Identified missing prices and categories; unresolved values flagged for verification. |
| Text Standardization | Standardized Product Name and Brand Name using consistent capitalization. |
| Error Correction | Corrected `Electroni` to `Electronics`. |
| Duplicate Removal | Removed exact duplicate rows based on all original columns. |
| Column Splitting | Separated Product ID into manufacturing date information and Country Code. |
| Column Merging | Combined Brand Name and Product Name into Product Brand. |
| Number Formatting | Applied currency formatting to Price. |
| Conditional Formatting | Applied data bars to Price and highlighted Electronics categories. |

## Dataset Summary

| Metric | Result |

| Original Records | 34 |
| Duplicate Records Removed | 3 |
| Final Records | 31 |
| Missing Price Values | 3 |
| Unresolved Category Values | 1 |

## Key Observations
- Three missing price values were retained as blank and flagged for verification.
- One missing (unknown) category remains unresolved pending source confirmation.
- The Product ID contains day, month and country code information but does not include a manufacturing year. Therefore, a complete date could not be derived without additional source information.
- The original dataset was preserved for reference.
